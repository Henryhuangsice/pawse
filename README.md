# Pawse 爪憩

> 打工人的桌面情感陪伴宠物 · An emotional-companion desktop pet for your workday.

Pawse 是一只住在你桌面角落的小宠物（像素飞猫 / 宇航员 / 战士）。它会自己走来走去，但只在你划定的区域里活动，不挡你干活；鼠标靠近时它会看向你，点它、摸它、拖它都有反应。后续版本会加入上下班陪伴、喝水/站立提醒、快捷启动、自定义形象、AI 对话和下班去处推荐（国内 + 海外）。

## M1 —— 会动、会互动、不打扰

- 三个内置形象，矢量分部件 / 视频帧图集 + **程序化动画**（呼吸、眨眼、视线跟随、走路、摇尾巴、挤压拉伸），各有一套渲染风格：
  - 🌈 **像素飞猫**（原创）：8-bit 像素画，一直悬浮飞行，身后拖着霓虹渐变尾迹和闪烁的星星；动作对齐像素网格、12 帧/秒步进
  - 🧑‍🚀 **宇航员**（Pixabay 免费素材，见 [CREDITS.md](CREDITS.md)）：绿幕视频抠像后做成帧图集；平时失重漂浮，移动时换成侧身漂移（朝向跟着方向翻转），点它常会向你挥手，鼠标靠近会朝你倾身，打盹时慢慢后仰下沉
  - ⚡ **战士**（原创形象）：更成熟的比例；悬停开始蓄力 → 金发、青色瞳孔、光盘气场、旋转六边形与速度线；点击“力量全开”
- 🖱️ **全局鼠标穿透**：只有宠物/气泡/菜单区域接收鼠标，其他地方的点击直接穿透到桌面
- 👀 悬停：看向你、脸红、跳一下；**来回在头上蹭 = 摸头**（爱心 + 呼噜）
- 👆 点击随机反应（跳、转圈、开心、挥手）；连点 5 下会生气；点醒睡觉的宠物
- ✋ 拖拽：像钟摆一样晃，落地有挤压回弹；拖出活动范围会自己走回去
- 🗺️ **活动范围**：在屏幕上直接框选，或用预设（右下角 / 底部一条 / 右侧一列 / 全屏）
- 💤 长时间没理它会打瞌睡
- ⚙️ 设置窗口（形象、名字、大小、活动范围、语言）+ 菜单栏托盘
- 🌏 中文 / English 双语，默认跟随系统

## M2 —— 上班搭子

- 🕘 **上下班**：设好工作日、上下班和午休时间，它会上班打卡问候（周一、周五有特别台词）、喊你吃午饭、下班道别并给点放松建议；下班后还在电脑前，每小时提醒一次早点休息。关闭“按工作时间陪伴”后提醒全天有效
- 💧🧍👀 **健康提醒**：喝水 / 起来活动 / 远眺（20-20-20），气泡里一键“完成”或“稍后”
  - 只计算**你在电脑前的时间**：键鼠空闲超过设定时长（默认 5 分钟）视为已起身，久坐和用眼计时清零，回来时说欢迎回来
  - 挑**断点**提醒：刚切换完应用、或你停下来几秒时；实在没断点，超时 5 分钟后才打断
  - 连续不理会自动**降频**（最多拉长到 2 倍间隔），点“完成”后恢复
- 🤫 **勿扰**：Zoom / 腾讯会议 / Teams / Webex / FaceTime 等在前台、或前台窗口全屏时不提醒、不闲聊；右键菜单可“勿扰 1 小时”
- 🚀 **快捷启动**：右键宠物或按 **⌃⌥P**（Windows: Ctrl+Alt+P）打开，填应用名、网址或应用路径；设置里可直接选已安装的应用
- 🙈 **不挡你**：宠物挑落脚点时会避开你正在用的窗口
- 🔁 开机自启

> 隐私：只读取“距上次键鼠操作多少秒”和“最前面窗口属于哪个应用、在哪个位置”，不读窗口标题、不截屏、不记录按键，也不需要辅助功能或屏幕录制权限。

## M3 —— 我的宠物

- 📷 **用照片做宠物**：选一张照片（自家猫狗、手办、自画像…），在本机自动抠图（U²-Net small，约 1 秒），**图片不上传**；也可以选择不抠图。做好的宠物会呼吸、蹦跳着走、朝你倾身、被拖时摆动
- ✨ **用文字生成**：描述你想要的样子，选画风（像素 / 扁平 / 3D 卡通 / 水彩 / Q 版），用你自己的 Key 调用 **通义万相**（国内）或 **OpenAI**（海外）生成，再本机抠图
  - API Key 存在系统钥匙串里，不写进配置文件；请求从 Rust 发出，Key 不进网页层
  - ⚠️ 目前只用模拟返回测过，还没用真实 Key 跑过
- 🎨 **换配色 + 配饰**：内置形象可以调色，戴皇冠 / 墨镜 / 蝴蝶结 / 耳机（自定义宠物可戴皇冠和蝴蝶结）
- 📦 **角色包**：把自定义宠物导出成 `.pawse` 文件分享给朋友，对方一键导入

## M4 —— 会聊天的伙伴

- 💬 **聊天**：右键宠物“聊聊天”或按 **⌃⌥C**（Windows: Ctrl+Alt+C），回复逐字显示在宠物旁边的对话框里
- 🆓 **默认免费**：默认接本机的 [Ollama](https://ollama.com)（推荐 `ollama pull qwen2.5:3b`），不花 token，聊天内容不出电脑；不想装东西就选**智谱 GLM-4.7-Flash** 或**硅基流动**的免费模型（注册拿个 Key 就行）；也可以换成 DeepSeek、通义千问、OpenAI 或任何兼容 OpenAI 的接口（LM Studio、Moonshot…），Key 存系统钥匙串
- 🔊 **语音**：聊天框右上角 🔈 打开后，用系统自带的声音朗读回复（macOS 用 `say`，免费、不联网）；想用说的，连按两下 Fn 用 macOS 听写输入
- ⚡ **本地指令**：“帮我打开微信”“十分钟后提醒我喝水”“半小时后叫我开会”“取消提醒”在本机直接识别执行，不调用模型，没接模型也能用；模型也可以通过工具调用做同样的事
- 🎭 **人格卡**：性格、说话风格、不要做的事，留空用每只宠物自带的性格
- 🧠 **记忆**：聊天记录和“它记得的关于你”存在本机 SQLite；最近的对话作为上下文，旧的自动整理成摘要（不记录密码、证件号等），设置里可查看、修改、一键清空
- 🤝 **不讨好、不黏人**：回复简短真诚、不奉承；鼓励你休息、按时下班、多和朋友家人联系；遇到情绪危机会建议联系身边的人或心理援助热线
- 🔕 **主动搭话限频**：默认关闭；开启后每天最多 N 次，开会、全屏、刚聊过时都不打扰

## 技术栈

| 层 | 选型 | 原因 |
|---|---|---|
| 桌面壳 | **Tauri 2**（Rust） | 跨 macOS / Windows，内存远小于 Electron，系统 API 走 Rust |
| 前端 | TypeScript + Vite（无框架） | 宠物窗口每帧渲染，保持轻量 |
| 动画 | SVG 分部件 + 程序化动画 | 不依赖序列帧美术；同一管线后续可驱动用户上传的图片 |

### 透明窗口与鼠标穿透是怎么做的

宠物住在一个覆盖整个主屏的透明无边框置顶窗口里，窗口默认 `ignore_cursor_events = true`（点击全部穿透）。Rust 后台线程每 33ms 读取一次全局鼠标坐标：

1. 把坐标转发给前端（所以即使不碰它，宠物也能看着你）；
2. 判断鼠标是否落在前端上报的“命中区域”（宠物、气泡、菜单）内，是的话才临时关闭穿透。

拖拽和框选活动范围时会加锁，整窗接收鼠标。

## 开发

需要：Node 20+、Rust（`brew install rust` 或 rustup）、macOS 上需要 Xcode Command Line Tools。

```bash
npm install
npm run tauri dev      # 开发运行
npm run tauri build    # 打包 .app / .dmg（Windows 上为 .msi / .exe）
```

> **macOS 链接报错 `tapi error: malformed file ... MacOSX27.0.sdk`？**
> 说明 Command Line Tools 默认 SDK 比自带链接器新。新建 `src-tauri/.cargo/config.toml`（已被 gitignore）：
> ```toml
> [env]
> SDKROOT = "/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk"
> ```

配置文件位置：`~/Library/Application Support/io.github.pawse.desktop/config.json`

src-tauri/src/custom.rs 自定义宠物存储、.pawse 角色包

public/models/         抠图模型
docs/ROADMAP.md        分阶段计划
```
