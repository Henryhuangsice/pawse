# Roadmap

原则：**先做到“不打扰”，再做“可爱”，最后做“聪明”。** 每个阶段结束都是一个可用版本，单独推送到 GitHub。

## ✅ M1 — 会动、会互动、不打扰
- [x] Tauri 2 透明置顶覆盖窗口 + 全局鼠标穿透（命中区域轮询）
- [x] 猫 / 狗 / 小人三套分部件矢量形象 + 程序化动画
- [x] 悬停视线跟随、摸头检测、点击反应、连点生气、拖拽钟摆 + 落地回弹
- [x] 行为状态机：闲置 / 漫步 / 打盹 / 被拖拽 / 走回活动区
- [x] 活动范围：屏幕框选 + 预设，持久化为屏幕比例
- [x] 设置窗口、菜单栏托盘、中英双语

## M2 — 上班搭子（有用而且不烦）
- [ ] 上下班时间、工作日设置；上班问候、午休、下班道别
- [ ] 喝水 / 站立 / 远眺（20-20-20）/ 休息提醒
  - [ ] **空闲感知**：键鼠空闲超过 N 分钟视为已离开，久坐计时自动重置
  - [ ] **勿扰**：全屏、屏幕共享、会议应用在前台、系统专注模式时静默
  - [ ] 尽量在任务断点（切换应用、长停顿后）提醒；可贪睡；连续忽略就自动降频
- [ ] 快捷启动器：常用应用 / 网址 / AI 工具，右键菜单 + 快捷键唤起
- [ ] 台词库扩充（按时段、星期、天气）
- [ ] 开机自启（tauri-plugin-autostart）
- [ ] 自动避开当前活动窗口（macOS: CGWindowList / Windows: GetForegroundWindow）

## M3 — 我的宠物（自定义形象）
- [ ] 上传图片 → 本地抠图（rembg / BiRefNet ONNX）→ 单图 + 程序化动画
- [ ] 颜色 / 配饰定制（换内置形象的配色）
- [ ] 文字描述 → 文生图（可选云端：国内通义万相 / 海外 OpenAI / Replicate）→ 抠图入库
- [ ] 角色包格式（导入导出、社区分享）

## M4 — 会聊天的伙伴（AI 陪伴）
- [ ] 点击 / 快捷键打开对话框，流式回复显示在气泡中
- [ ] 人格卡（性格、说话风格、禁忌）
- [ ] 记忆：短期上下文 + 长期摘要（本地 SQLite）
- [ ] 工具调用：“帮我打开微信”→ 启动器；“十分钟后提醒我”→ 定时器
- [ ] 模型可配：云端 API（海外 / 国内）或本地 Ollama；API Key 存系统钥匙串
- [ ] 主动发言限频，避免讨好与情感依赖

## M5 — 下班去哪儿 + 发布
- [ ] 城市 / 公司地址设置（不强制定位）
- [ ] 国内：高德 POI 搜索（酒吧、Livehouse、公园、餐厅）+ 大众点评 / 大麦跳转
- [ ] 海外：Google Places / Yelp Fusion + Ticketmaster Discovery（演出）
- [ ] 结合天气与星期几的推荐策略
- [ ] Windows 适配与测试、多显示器、高分屏
- [ ] macOS 签名公证、自动更新（tauri-plugin-updater）、GitHub Actions 发布
