# Roadmap

原则：**先做到“不打扰”，再做“可爱”，最后做“聪明”。** 每个阶段结束都是一个可用版本，单独推送到 GitHub。

## ✅ M1 — 会动、会互动、不打扰
- [x] Tauri 2 透明置顶覆盖窗口 + 全局鼠标穿透（命中区域轮询）
- [x] 猫 / 狗 / 小人三套分部件矢量形象 + 程序化动画
- [x] 悬停视线跟随、摸头检测、点击反应、连点生气、拖拽钟摆 + 落地回弹
- [x] 行为状态机：闲置 / 漫步 / 打盹 / 被拖拽 / 走回活动区
- [x] 活动范围：屏幕框选 + 预设，持久化为屏幕比例
- [x] 设置窗口、菜单栏托盘、中英双语

## ✅ M2 — 上班搭子（有用而且不烦）
- [x] 上下班时间、工作日、午休设置；上班问候（周一 / 周五特别版）、午饭、下午场、下班道别 + 放松建议、加班提醒
- [x] 喝水 / 起来活动 / 远眺（20-20-20）提醒，气泡里一键“完成 / 稍后”
  - [x] **空闲感知**：键鼠空闲超过 N 分钟视为已离开，久坐 / 用眼计时自动重置，回来时欢迎
  - [x] **勿扰**：会议应用在前台、全屏、手动“勿扰 1 小时”时静默
  - [x] 尽量在任务断点（切换应用后、停顿时）提醒；可贪睡；连续忽略自动降频（最多 2 倍间隔）
- [x] 快捷启动器：应用名 / 网址 / 应用路径，右键菜单 + 全局快捷键 ⌃⌥P 唤起，设置里可选已安装应用
- [x] 台词库扩充（按时段、星期）
- [x] 开机自启（tauri-plugin-autostart）
- [x] 自动避开当前活动窗口（macOS: CGWindowList，只读应用名和窗口位置）
- 留到后面：天气台词（随 M5 天气接口）、系统专注模式 / 屏幕共享检测、浏览器里开的会议（需要读窗口标题，涉及隐私权限）、Windows 版空闲时间与前台窗口（M5 Windows 适配）

## ✅ M3 — 我的宠物（自定义形象）
- [x] 上传图片 → 本地抠图（U²-Net small ONNX，onnxruntime-web 在本机运行，图片不上传）→ 单图 + 整体程序化动画（呼吸、蹦跳步、倾身、翻转、拖拽摆动）
- [x] 颜色 / 配饰定制：内置形象调色（色相旋转，保留描边/肤色/白色）+ 皇冠、墨镜、蝴蝶结、耳机，配饰跟随头部动
- [x] 文字描述 → 文生图（国内通义万相 / 海外 OpenAI，自带 Key 存系统钥匙串，请求从 Rust 发出）→ 本地抠图入库
  - ⚠️ 接口已留，只用模拟返回测过整条流程，还没有用真实 Key 调用过；有 Key 后先实测一次
- [x] 角色包格式 `.pawse`（JSON + 内嵌 PNG），导入导出
- 留到后面：更高质量的抠图模型（可选下载）、手动修边、自定义形象的多帧动作、Replicate 等更多服务商

## ✅ M4 — 会聊天的伙伴（AI 陪伴）
- [x] 右键菜单 / 快捷键 ⌃⌥C 打开对话框，流式回复逐字显示
- [x] 人格卡（性格、说话风格、不要做的事），留空用每只宠物自带的性格
- [x] 记忆：短期上下文（最近 12 条、6 小时内）+ 长期摘要（本地 SQLite，攒够 30 条自动整理），设置里可看、可改、可清空
- [x] 工具调用：“帮我打开微信”→ 启动器；“十分钟后提醒我”→ 定时器。常用说法先在本地识别（不花 token、离线可用），模型也能通过 function calling 调用
- [x] 模型可配：本地 Ollama（默认，免费）、DeepSeek、通义千问、OpenAI、任意 OpenAI 兼容接口；API Key 存系统钥匙串
- [x] 主动发言限频（默认关，每天最多 N 次、间隔 ≥ 90 分钟、开会/全屏/刚聊过不说），提示词约束不讨好、不制造情感依赖
- ⚠️ 只用模拟服务端测过（Rust 流式解析单测 + 浏览器模拟），还没接真实模型跑过；装好 Ollama 后先实测一次
- [x] 免费云端模型一键选：智谱 GLM-4.7-Flash、硅基流动 Qwen2.5-7B（不用装 Ollama）
- [x] 朗读回复（系统声音，免费离线）；语音输入先用 macOS 听写（连按两下 Fn）
- 留到后面：云端语音识别（硅基流动 SenseVoice / 阿里 Paraformer / Groq Whisper，按需再接）、好听的云端音色（CosyVoice 等，付费）、聊天里发图片、定时器重启后补响超过 10 分钟的、Ollama 一键安装引导

## M5 — 下班去哪儿 + 发布
### ✅ 上半：下班去哪儿
- [x] 城市设置（手填，不读取定位）；天气来自 Open-Meteo（免费、无 Key）
- [x] 21 个主意 × 6 类（吃 / 喝一杯 / 运动 / 演出电影 / 逛逛 / 回家歇着），按天气（雨雪不推户外、冷热各有偏好）、星期几（周五周六偏演出和小酒馆）、时间（21 点后劝回家）、用户偏好打分挑 3 个不同类的
- [x] 国内跳高德 / 小红书 / 大麦搜索，海外跳 Google Maps / Yelp / Ticketmaster；按城市所在国家自动选
- [x] 入口：右键菜单、聊天里说「今晚去哪」（本地识别）、下班时气泡询问（可关）
- 改动：原计划的高德 POI / Google Places / Yelp Fusion 接口都要 Key，有的还收费，先用搜索跳转代替；以后如果需要“附近真实店铺 + 评分”，可以加一个可选的高德 Key（个人开发者有免费额度）
- 留到后面：天气台词（下雨提醒带伞等）、记住常去的地方、和朋友一起的提议
